# dmb-timerd
Отслеживает оставшееся и прошедшее время до демобилизации. Взаимодействие через Telegram

## Требования
- GNU/Linux дистибутив
- Доступ к интернету

## Зависимости
- `cjson`
- `curl`
- `gcc`
- `make`

## Сборка и установка
1. Сконфигурировать программу
```bash
./configure.sh
```
2. Собрать программу
```bash
make
```
3. Установить программу (нужны root права)
```bash
make install
```

## Запуск
Запустить программу (нужны root права)
- Systemd
```bash
systemctl enable --now dmb-timerd.service
```
- Нативно
```bash
dmb-timerd
```
